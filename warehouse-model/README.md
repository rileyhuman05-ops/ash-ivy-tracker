# Bayline warehouse model

Canonical self-contained Three.js warehouse viewer for Bayline Mesa.

| File | Notes |
| --- | --- |
| `warehouse-site-preview-v3.html` | ~1.4MB offline viewer (embedded GLB + inventory). Embedded title may still say “preview v2”; treat this file as the **v3** upload. |

The live Cursor app at the repo root serves this HTML only after `WAREHOUSE_USERNAME` / `WAREHOUSE_PASSWORD` auth. Do not place copies under a public static folder.
